# 芦荡薪火 · 沙家浜红色美育门户

根据项目 PPT 制作的响应式静态门户，可直接部署到 GitHub Pages。无构建依赖，无第三方字体、图片 CDN 或统计脚本。

## 页面与交互

- 首页：项目定位、三阶段美育目标、体验入口、文创与实践记录。
- 走近项目：研究背景、理论依据、5+X 模式、调研、已有与计划成果、N=30 前后测数据、PPT 原稿节选。
- 文创商城：三类商品、关键词搜索、价格排序、款式、数量、购物袋与订单草稿。
- 活动预约：剧本杀学生专场/成人社区场、人数/年龄段，春夏秋冬课程，单日营/系列课，五步预约与草稿下载。
- 美育足迹：田野调研、创意表达、校园实践与详情阅读。

## 运行

安装 Node.js 后，在本目录执行 `npm run dev`，打开 http://127.0.0.1:8877。

语法检查：`npm run check`。页面源码位于 `site/`。

## 当前状态

当前为明确标记的**演示版**。用户尚未提供正式价格、排期、运营联系方式、订单接口或支付配置。

商品图片和实践照片来自用户提供的 PPT；价格、款式和周末排期为演示数据。网站不会真实收款、发送订单、确认预约名额或发货。下载的文本文件仅为本地草稿。

购物袋的商品编号、款式、数量可以在浏览器保存。联系人、电话、地址不写入 localStorage；关闭弹窗即清除当前个人信息。用户主动下载的文件由用户保管。

## 设计要求

- 主色 `#C00000`，辅色 `#D22C3B`、`#FFF2CA`、`#CFA669`，取自 PPT。
- 中文采用宋体；英文和数字采用 Times New Roman。样式栈先匹配 Times New Roman 拉丁字符，再匹配 SimSun/宋体中文字符。
- 数学表达使用 MathML，并指定 Cambria Math；不以图片或普通斜体文本冒充公式。
- 不支持这些字体的平台会使用系统衬线字体回退。为保证跨平台字体一致，可以在取得字体授权后自行提供字体文件。
- 支持手机、键盘操作、对话框焦点、表单标签、减弱动画偏好。

## 发布与维护

源码保存在 `main`，网站发布到 `gh-pages` 分支根目录。GitHub 仓库 Settings → Pages → Source 为 **Deploy from a branch**，选择 `gh-pages` / `/ (root)`。

修改并提交源码后，在 PowerShell 执行 `./scripts/publish-pages.ps1`，脚本先检查 JavaScript，然后从 `site/` 提取发布提交并推送至 `gh-pages`。GitHub Pages 会自动构建该分支。

本次 GitHub OAuth 授权未包含 `workflow` scope，因此使用原生分支部署，无需新增授权。工作区另保留未跟踪的 GitHub Actions 工作流示例，供未来取得相应权限后使用。

常改文件：

- `site/content.js`：商品、价格、款式、课程、实践记录。
- `site/config.js`：演示/正式模式、服务接口、联系邮箱、正式场次。
- `site/styles.css`：主题颜色、字体、布局。
- `site/app.js`：页面、购物与预约流程。

正式运营接入说明见 [docs/INTEGRATION.md](docs/INTEGRATION.md)。内容口径见 [docs/CONTENT_NOTES.md](docs/CONTENT_NOTES.md)。
